# Using Superpowers

Select a skill when its description fits the task or the user explicitly requests it. Follow the user's instructions and repository requirements.

- For clear, reversible work, inspect what matters, make the change, and verify it.
- For an unresolved design decision with meaningful consequences, use [brainstorming](../brainstorming/SKILL.md). For complex sequencing or handoff, use [writing-plans](../writing-plans/SKILL.md).
- For a flaky, recurring, or poorly understood failure, use [systematic-debugging](../systematic-debugging/SKILL.md).
- For work that explicitly requires test-first development, use [test-driven-development](../test-driven-development/SKILL.md).
- Before reporting an implementation result, use [verification-before-completion](../verification-before-completion/SKILL.md).
- The main agent owns execution. Delegate when the user or applicable project instructions request it. Use an existing checkout or worktree by default, and isolate work when needed and authorized.

On Codex, consult [Codex tools](references/codex-tools.md) when you need help with delegation or worktrees.
