# Dispatching Parallel Agents

1. Split the work into independent questions or nonoverlapping write scopes. Match the number of agents to the number of useful independent tasks.
2. Give each agent the objective, relevant context, limits, and an expected result with evidence. Read-only investigation and independent review work well with separate context.
3. Keep overlapping edits and tasks with sequential dependencies under one owner. Use the main agent for short file reads and closely related tasks.
4. Compare the results against the source files, reconcile disagreements, integrate any edits, and verify the combined result.
